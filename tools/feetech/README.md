## 灵影可以直接配合 FD 使用

灵影 TTL Adapter(A) 是 USB 转舵机 TTL 总线适配器；设置飞特 HD-1910-C001 的 ID，可以直接使用本目录飞特 FD 软件，不必为此更换成飞特品牌调试板。

1. USB 连接电脑与灵影板。系统应出现 COM 端口；如果没有，查看板上 USB 串口芯片型号，按灵影厂商说明安装对应驱动。不要凭“TTL”字样随意安装驱动。
2. 按适配器说明给舵机供电，核对 GND、电源和 DATA。USB 接入电脑不代表舵机电源已经接通；不要把 RS-485 接口当 TTL 使用。
3. **一次只接一颗舵机。**用已核对线序的 `5264-3P → AMP2.0` 调试线连接灵影与该舵机。它与装机互连线是两个用途。
4. 解压 FD 软件，选中设备管理器对应 COM 端口，波特率选 `1000000`（1 Mbps），打开端口、搜索。
5. 搜到一颗后停止搜索，选中该舵机，在参数/编程页将 ID 改为目标编号并写入保存。禁止多颗相同出厂 ID 同时接入改号。
6. 重新断电上电，按新 ID 再搜一次，确认型号与位置反馈正常。型号识别异常时先用官方最新版核对，不导入其他型号参数。
7. 舵机尚未装进骨架、舵盘可自由运动时，在位置控制中低速移到 `2048`；核对回读后贴上 ID 标签，再拔下换下一颗。不要用“校准中位”改写编码器偏移来替代移动到 2048。

编号以鸭子自身左右为准，后视方向（鸭子背对你）：

| 部位 | ID 顺序 |
|---|---|
| 左腿 | 20 转向、21 侧摆、22 前后、23 膝、24 踝 |
| 右腿 | 10 转向、11 侧摆、12 前后、13 膝、14 踝 |
| 头部 | 30 脖子、31 点头、32 转头、33 歪头、34 嘴 |

不能搜索到舵机时按顺序检查：COM 是否出现、端口是否被其他软件占用、是否 1 Mbps、舵机供电、线序和接触。完成后关闭 FD 串口；不要让两个程序同时占用同一个适配器。
