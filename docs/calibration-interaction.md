# 标定向导交互逻辑

当前实现是单文件演示，不连接机器人；标定、修正和检查结果只在当前页面会话中保存。刷新后重置。

网站主入口指向本机部署与版本说明。`backend/` 提供独立的真实 SSH 调试后台和界面，在 `127.0.0.1:8098` 运行，通过匹配的机器人 `robotd` 服务读取总线、采集标定、卸力和单颗回中位；能力、固件要求和验证边界见 [backend/README.md](../backend/README.md)。

下述七步仍描述 `tool/calibration.html` 的流程演示，在线 `/tool/` 和 `python -m http.server` 的静态预览都使用模拟数据，不连接后台、不写入机器人。演示连接页明确提示不填真实 SSH 密码；真实后台才接受本次连接需要的 SSH 凭据，且不保存密码。

## 主流程

连接 → 检查 15 颗舵机 → 摆零位 → IMU → 摄像头 / ToF（同一步、可选）→ 试站 → 手柄（可选）→ 完成。

必要步骤按现有前置条件限制跳转。摄像头 / ToF 只依赖连接，不作为试站的前置条件；正常流程仍会经过它们，由用户确认或明确跳过。

## 摄像头 / ToF

1. 同一页显示画面和 8×8 深度矩阵，仅在这一页运行演示采集。
2. 摄像头需确认画面正常；ToF 需先看到无遮挡，再检测到手靠近。
3. 两个设备分别记录「待检查 / 已检查 / 已跳过」。允许通过一个、跳过另一个。
4. 两项都已处理后可继续；「跳过未检查项，继续」只跳过尚未通过的项，保留已通过的结果。
5. 故障不阻断跳过。重试只清除当前设备的通过状态，不清除另一个。
6. 完成页逐项展示结果，补做仍进入同一个传感器步骤；通过后清除对应跳过状态。

## 试站与局部修正

试站 → 对照姿态 → 有偏差 → 选择关节或部位：

- 小偏差：单关节微调。
- 零位摆错、拆装过：单关节重标，或整个部位重新摆零位。
- 站姿正常但行走有偏差：按走弧线、侧移、摇晃分类排查，先看输入、机械装配、承重与反馈，再考虑增益。

### 单关节微调

选择关节 → 编辑草稿 → 确认已停止行走并支撑机身 → 小幅试用 → 判断效果 → 保存 → 重新试站。

- 步长 0.1° / 0.5°，草稿范围 ±3°；这是本版原型的交互边界，需实机验证。
- 保留原始零位和独立修正；有效零位 = round(原始零位 + direction × 修正弧度 × 4096 / 2π)。
- 反馈角、目标换算、限位校验和 TOML 导出共用有效零位，编码器按整格取值。
- 编辑不执行运动；只有试用按钮改变模拟目标。试用中禁止切换和重复操作。
- 保存必须对应最后一次试用的草稿。试用后再编辑，必须重新试用。
- 试用和保存前检查单圈边界、HOME 是否处于限位内。
- 可以撤销草稿、恢复原始标定（仍需试用并保存），或取消并恢复上次保存值。
- 离开未保存的草稿需选择继续调整或放弃；刷新时提示存在未保存草稿。
- 保存会使试站和手柄确认失效，保留 IMU 与传感器检查结果；重新确认站姿后才能继续。

### 单关节重标

选择关节 → 支撑并松开 → 按模型摆零位 → 确认摆好 → 校验读数 → 保存 → 重新试站。

只替换选中关节的零位，清除该关节旧微调；其他 14 颗及其修正保留。取消或校验失败不修改原值。整个部位重标只清除对应部位。

## 结果与恢复

本次修正保留最近 20 条记录。完成页可回到关节复查或补做可选传感器检查。PID 不做无实机反馈的自动推荐或隐式改写。
