本机调试和在线演示使用不同入口

本机后台显示真实 SSH 与 robotd 数据。本站的七步页面仍是模拟流程，用于熟悉操作；它不连接本机后台，不会写入机器人，也不要在演示页填真实密码。

在自己的电脑上部署

  1. 下载并完整解压：下载上面的本机调试包，或获取 GitHub 源码。需要 Python 3.9 或更新版本，首次启动需联网安装依赖。
  2. 启动本机后台：macOS 可双击 start.command，或在项目目录运行 bash start.command；Windows 安装 Python（含 Launcher）后双击 start.cmd；Linux 同样运行 bash start.command。
  3. 在自己的电脑打开：启动器会打开 http://127.0.0.1:8098/。填写机器人 SSH 地址和密码，或使用已经配置好的密钥；首次连接需核对 SSH 主机指纹。
  4. 确认固件接口：机器人需已运行支持 robot.busStatus 与 robot.busCommand 的飞特版 robotd，默认 socket 为 /run/robotd.sock。写入标定前须按固件说明进入 commissioning 模式；本工具不会替你安装或切换固件。
  5. 读取、再采集：核对总线和 IMU 反馈，支撑机身并卸力，手动摆到已知角度；填写实测方向与限位，再写入选中关节的标定。卸力可随时单独操作，单颗回中位要求先拆下舵盘。

真实功能与验收范围

后台已实现真实 SSH、总线/IMU 原始反馈、标定读取与单关节写入、IMU 安装确认、卸力、单颗回中位。本次通过协议夹具和自动测试验证，尚未在真实机器人上验收；首次使用先核对固件和只读反馈。摄像头视频、ToF 服务、手柄配对和行走策略未接入这个后台。

装机前的 ID 编号使用 灵影 TTL Adapter(A) + 仓库随附飞特 FD 软件。它通过 USB 串口连接单颗舵机，与装机后的 SSH 调试后台是两条不同流程。

演示工具里的七步

  1. 连接填 MicroDuck 的地址，连上主控。
  2. 检查15 颗舵机全部正常在线。哪颗有问题，会直接告诉你 ID。
  3. 摆零位照屏幕把腿和头摆正，一次设一条腿，也可以一颗一颗设。
  4. 姿态传感器扶正、前倾、左倾，各停一下。
  5. 摄像头 / ToF（可选）同一页确认画面和距离变化，可以单独跳过某一项，也可以直接跳过未检查项。
  6. 试站让它慢慢站起来，对照屏幕看姿势。局部有偏差，可以只重标一颗，或小幅微调、试用后再保存。
  7. 手柄连上手柄，学几个常用按键。

试站后只修正有偏差的关节

在“有偏差，调整”中选择关节。微调支持 0.1° 和 0.5° 步长，先试用，效果合适再保存；修改后重新试站确认。明显摆错或拆装过，就重标那颗关节，其他关节的结果会保留。每颗最多调 ±3°，先“试用”，效果合适再“保存”，保存后要重新试站。

摄像头和 ToF 已放进第 5 步；跳过结果会保留在完成页，之后可以补做。

结果只在当前页面保留

标定、微调和检查结果都只在当前页面会话里保留，刷新后重置；刷新时如果有没保存的微调，会先提示。完整的交互规则在 GitHub 的交互说明 ↗。

接下来：部署训练实验室

训练实验室是另一个需要在自己电脑上安装、启动的项目。它用于仿真训练、世界模拟和动作编辑，源码与安装步骤见 microduck-lab-cloud 快速开始 ↗。

训练方式怎么使用
Mac M 系列 CPU 本地训练可在 Apple Silicon Mac 上使用 CPU 训练支持的动作，无需独立 NVIDIA 显卡，也无需 Google 登录。启动本地实验室后，在“训练”中选择动作，再点“CPU 训练”。
Google Colab 云端训练使用自己的 Google 账号，可尝试 Colab 免费层提供的云算力，包括可用时的 T4 GPU。按项目云端说明选择兼容任务；也可打开训练 Notebook，在 Colab 网页中运行。

Colab 免费算力的可用性、GPU 型号、运行时长和使用限制由 Google 动态决定，不保证分配，也没有固定免费小时数。付费计算单元另计，详情见 Google Colab 官方说明 ↗。

本地 CPU 与云端支持的训练任务可能不同，以实验室中各动作的可用选项为准。飞特 HD-1910 和官方 XL330 要使用对应的仿真与控制参数，训练结果不能未经核对就直接部署到真机。
