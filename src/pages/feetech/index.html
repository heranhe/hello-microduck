飞特 HD-1910 方案

用飞特舵机做一只 MicroDuck

五步都在这一页，向下滑动就能连续看完。也可以点目录，直接跳到要做的步骤。

  1. 准备材料和打印采购清单、打印外壳。
  2. 给舵机设 ID15 颗舵机各设一个编号，顺便转到中位。
  3. 主板、HAT 和接线摄像头排线、焊 ToF、舵机线序，最后装舵机。
  4. 写入系统、通电一键写 TF 卡、插卡方向、哪个 C 口供电。
  5. 用调试工具标定下载本机后台，通过 SSH 读取实机反馈并采集标定；在线页面仅演示流程。

这个方案换了舵机，先确认 HAT 的版本。原版 HAT 和飞特舵机的线序不同；推荐的飞特兼容版可直接兼容飞特舵机线，第 3 步会分别说明。不确定的地方，先停下来对照板上标注和接线图。
